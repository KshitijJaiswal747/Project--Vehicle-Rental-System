# Vehicle Rental System

Vehicle Rental Management System built with Python and Django.

**Author:** Kshitij Akash Jaiswal

## Features

- **User Registration** — captures customer name, phone number, and address at signup
- **Vehicle Booking** — select a vehicle, quantity, and pickup point
- **Vehicle Availability** — tracks how many vehicles are in stock
- **Billing** — calculates the rental cost and generates a receipt
- **Rental History** — view past bookings

## Technologies

- Python
- Django
- HTML / CSS
- SQLite
- JSON
